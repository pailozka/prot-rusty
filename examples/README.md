# Small offline example

All files here are synthetic fixtures authored for this project. The vectors were constructed by hand, not generated by a protein language model; sequences and category names are artificial. Do not use their scores as scientific evidence.

- `embeddings.csv`: eight vectors in four dimensions, without sequences.
- `annotations.csv`: two artificial families plus an origin column, deliberately in a different ID order.
- `sequences.fasta`: optional sequences to attach by ID.

Use **Load small synthetic example** in the app, or import these CSVs manually. Then inspect neighbors, switch 2D/3D, color by family/origin, filter categories, and save/reopen a project. For sequence inspection, import the FASTA and attach it to the loaded proteins.

```sh
cargo run --offline -- --evaluate examples/embeddings.csv examples/annotations.csv family 3 /tmp/protrust-report.json
```

Expected fixture results: top-1 accuracy 1.0, precision@3 1.0, macro precision@3 1.0, random-neighbor expected precision 3/7. These simply confirm the hand-constructed groups are separated and that the calculation works.
